# Omniri
Omniri is my personal desktop environment.

Window Manager: Niri - A scrollable-tiling Wayland compositor.

https://github.com/niri-wm/niri

Shell: Noctalia **v5** - A sleek, customizable desktop shell crafted for Wayland.

https://github.com/noctalia-dev/noctalia

Greeter: Noctalia Greeter - A greetd greeter, tightly coupled with Noctalia.

https://github.com/noctalia-dev/noctalia-greeter

polkit_gnome - Looking to replace / Find a decent way to setup Noctalia's polkit auth agent.

https://gitlab.gnome.org/Archive/policykit-gnome
